一、新项目第一次上传（只做一次）

  1. 在 github.com 点 New repository，起名，选 Public，不要勾选自动生成 README / .gitignore / license（本地已有内容时勾了会冲突）。
  2. 本地进入项目文件夹，依次执行：

-u 只在第一次需要，之后直接 git push 就行。

二、日常更新（常用）

想成”改文件 → add → commit → push”四步循环。commit 在本地存快照，push 才会上传到 GitHub。

三、几个容易踩的点

  • 先 git status 再 commit：绿色是已暂存，红色是没加上的，未跟踪文件要 add 才会进去。你这次的空提交就是漏了这一步。
  • commit 信息写清楚：比如 Add README、Replace hardcoded paths with CLI args、Add eval results，别全写 update。一个 commit 做一件事，记录会好看很多。
  • .gitignore 第一次就建好：放不想上传的东西，比如： 注意 .gitignore 对已经提交过的文件不起作用，要先 git rm --cached 文件名。
  • 别提交大文件和密钥：权重、数据集、API key（wandb、HuggingFace token）一律不进仓库。GitHub 单文件超过 100MB 会直接拒绝。密钥一旦推上去，即使删了也在历史里，需要作废重新生成。
  • 推之前先拉：如果你在网页上直接改过文件（比如在 GitHub 上编辑了 README），本地推送会被拒绝，先 git pull 再 git push。
