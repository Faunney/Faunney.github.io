1. 模型与优化（Optimization）

EMA（指数移动平均）

定义：训练时除了梯度下降正常更新的参数 θ_t，额外维护一份影子参数 θ_shadow，它跟着真实参数走，但更新得更慢，不参与反向传播，只是被动更新：

decay 一般取 0.999。

为什么重要：eval 时用 θ_shadow 通常比用最后一步的 θ_t 更稳定、泛化更好，因为 shadow 参数相当于把训练后期的参数抖动做了平均。

踩过的坑：最初以为 use_ema 是可选的性能优化，后来发现有的官方基准（比如 lerobot/diffusion_pusht）反而没开这个选项，说明它不是”越复杂越好”，要看具体基准配置。

关联概念：batch_size（同样影响训练稳定性）、图像增强（同样服务于泛化）

batch size (批次大小)

定义：训练完一个批次进行一次参数更新，一个批次中的样本数即 batch size。

为什么重要：batch size 越大，训练越快，且效果可能更好，因为单次参数更新的综合了更多案例，泛化性更强，但也更易过拟合。又因同一批次训练时采用并行计算，batch size 过大可能导致显存不足。

踩过的坑：若想复现baseline，需格外注意原版 batch size 设置，直接关系到能否获得相似结果。
