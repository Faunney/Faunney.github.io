1. 模型与优化（Optimization）

EMA（指数移动平均）

定义：训练时除了梯度下降正常更新的参数 θ_t，额外维护一份影子参数 θ_shadow，它跟着真实参数走，但更新得更慢，不参与反向传播，只是被动更新：

decay 一般取 0.999。

为什么重要：eval 时用 θ_shadow 通常比用最后一步的 θ_t 更稳定、泛化更好，因为 shadow 参数相当于把训练后期的参数抖动做了平均。

踩过的坑：最初以为 use_ema 是可选的性能优化，后来发现有的官方基准（比如 lerobot/diffusion_pusht）反而没开这个选项，说明它不是”越复杂越好”，要看具体基准配置。

关联概念：batch_size（同样影响训练稳定性）、图像增强（同样服务于泛化）

batch size (批次大小)

定义：模型每处理完一个 batch（一批样本）就计算一次梯度、更新一次参数，这批样本的数量就是 batch size。它决定了每次参数更新时，梯度是基于多少个样本的信息综合出来的。

为什么重要：batch size 越大，单次梯度估计包含的样本信息越多、噪声越小，梯度方向更稳定，同样步数下往往能达到更好的效果；但代价是显存占用随 batch size 线性增长，过大会直接导致 OOM。另外 batch size 和学习率不是独立的——batch size 变大后梯度噪声变小，通常需要相应调大学习率（linear scaling rule），否则同样的学习率会显得”步子迈得太小”，收敛变慢。

踩过的坑：如果目标是复现某个 baseline，batch size 必须和原始设置对齐，而不能只对齐 steps 数——因为两者共同决定了模型实际”看过”多少样本（有效训练量 ≈ batch_size × steps）。

关联概念：EMA（batch size 影响梯度噪声，间接影响 shadow 参数的平滑效果是否必要）、学习率调度（batch size 变化时学习率通常要联动调整）

学习率调度（warmup、cosine decay…）

定义：动态调整学习率。最常见的组合是「warmup + cosine decay」：训练最初的若干步，学习率从一个很小的值线性增长到设定的峰值（warmup）；之后再按余弦函数的形状，从峰值逐渐衰减到接近 0（cosine decay）。

为什么重要：训练刚开始时参数是随机初始化的，梯度方向往往很不准，如果一上来就用较大的学习率，容易在初期就把参数带偏甚至训练发散，所以需要 warmup 先”热身”；而训练后期参数已经比较接近最优点，需要用小学习率做精细调整，否则容易在最优点附近来回震荡而无法收敛，这就是 decay 阶段的作用。

踩过的坑：训练时第一次设置 steps 为100k，训练结束后加载last checkpoint并更改 steps 为200k继续训练，此时 loss曲线 会呈现波动（如下图）。

排查后发现，原因在于学习率调度是按照「当前 step / step 总数」这个比例来计算 衰减进度 的——第一次训练时，调度器以为总共只训 100k 步，所以在接近 100k 步时学习率已经衰减到很低；续训时把总步数改成了 200k，调度器重新按新的总步数计算衰减进度，导致学习率在续训起点被重新”拉高”了一截，直接反映成 loss 曲线在衔接处的波动。learning rate 曲线证实了这一点：

关联概念：batch size（steps 和 batch size 共同决定有效训练量，调度器的衰减进度是按 steps 而非样本数计算的）、优化器（不同优化器对学习率的敏感度不同，Adam 类优化器相对更能容忍学习率的波动）

优化器（Adam、SGD、AdamW等）

定义：优化器决定了「已经算出梯度之后，具体怎么用这个梯度去更新参数」。几种常见优化器的核心区别：

  • SGD：最朴素的方式，直接用当前梯度乘以学习率去更新参数：θ = θ - lr × grad。梯度里有多少噪声，更新方向就带多少噪声，容易震荡。
  • Momentum（动量法）：不直接用当前梯度更新，而是维护一个”历史梯度的指数移动平均”（和 EMA 的思路是一致的），让更新方向更平滑，减少震荡，也能在梯度方向一致的维度上加速收敛。
  • Adam：在 Momentum 的基础上，再对每个参数维度维护一份”梯度平方的指数移动平均”，用它来给每个参数各自的学习率做自适应缩放——梯度一直很大的方向，实际步长会被适当调小；梯度一直很小的方向，步长会被适当放大。这让 Adam 对学习率的初始设置相对没那么敏感，也是它成为深度学习默认选择的原因之一。
  • AdamW：和 Adam 几乎一样，唯一区别是把权重衰减（weight decay，一种防止过拟合的正则化手段）从梯度更新公式里解耦出来，直接作用在参数上，而不是先混进梯度里再一起做自适应缩放。这样权重衰减的力度不会被 Adam 的自适应机制意外放大或缩小，效果更符合预期，现在大多数 Transformer / 扩散模型的训练都默认用 AdamW。

为什么重要：扩散模型的训练目标（预测噪声）本身梯度噪声就比较大，Adam / AdamW 这类自适应优化器能让训练在不用非常精细调学习率的情况下也能稳定收敛，这也是为什么这类模型的官方实现里几乎都默认用 AdamW，而不是 SGD。

关联概念：学习率调度（优化器和调度器是配合工作的两个模块，调度器决定学习率的”基准值”随时间怎么变，优化器决定每个参数实际拿到的”有效学习率”怎么自适应缩放）、EMA（Momentum 和 EMA 用的是同一种指数移动平均的数学工具，只是作用对象不同——一个平滑梯度，一个平滑参数）

4. 评估与实验设计（Evaluation & Experimental Design）

Beta 后验 / 可信区间

定义：

  • 首先解释先验/后验：
    • 先验 (prior)：看到数据前，对某个未知量的概率分布假设。
    • 后验 (posterior)：结合数据后，更新出来的新的概率分布。
  • beta 分布：定义在 [0,1] 上的分布，专门用来描述”未知的概率/比例”（比如真实成功率），由两个参数控制形状。
  • beta 后验：Beta 分布是二项似然的共轭先验——先验 Beta(α,β)，观测到 n 次实验 k 次成功后，后验就是 Beta(α+k, β+n-k)，闭式解，不用采样。从最无信息的 Beta(1,1) 出发，后验就是 Beta(k+1, n-k+1)。
    • “先验是 Beta 分布 Beta(α, β) + 似然是伯努利/二项分布” 这个特定组合,才保证后验一定是 Beta(α+k, β+n-k)。
  • 置信区间 (confidence interval): 频率学派。真实值是固定的，区间才是随机的——“重复抽样很多次，这些区间里大约 n% 会包住真实值”。
  • 可信区间 (credible interval): 贝叶斯。真实值本身被当作随机变量，直接从后验分布切一刀——“真实值有 n% 的可能落在这个区间内”。（这个概念更易懂一些）

为什么重要：小样本对照实验里，不能只比较两个点估计的大小（比如 47% vs 43%），因为样本量小的时候，点估计本身的抽样噪声可能远大于这个差距。可信区间把”这个点估计到底有多不确定”量化了出来，用两组区间是否大幅重叠，就能判断当前数据是否足以支撑”两者存在真实差异”这个结论，避免仅凭一次抽样的数字大小就下结论。

踩过的坑：区间重叠 ≠ “两者真实值相等的概率大”。重叠说明的是数据不够信息量去区分。真要比较谁更好，得直接对两个后验做差值推断（比如采样算 P(θ_A > θ_B)），不是看区间重不重叠。
